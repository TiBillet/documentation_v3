Lire un rapport¶

Un rapport de ventes TiBillet permet de comprendre précisément ce qui s’est passé sur une période donnée : ce qui a été vendu, comment les clients ont payé, combien de TVA a été collectée, et combien d’argent doit se trouver dans la caisse.

Que vous utilisiez le Rapport classique, le Ticket Z ou le Rapport V2 (bêta), la logique reste la même : le rapport est une photographie comptable d’un moment précis.

Comprendre la période du rapport¶

En haut du document, vous retrouvez toujours :

  • le nom du lieu

  • la date de début

  • la date de fin

Cela vous permet de savoir à quel service ou quelle journée correspond le rapport.

Les ventes par moyen de paiement¶

Cette partie indique comment les clients ont payé leurs achats : espèces, carte bancaire, local (cashless rechargé sur place), fédéré (recharge par QR code), En ligne (paiement direct sur Stripe); externe (cashless rechargé dans un autre lieu)...

Elle ne comprend pas les recharges cashless, uniquement les ventes réelles.

C’est ici que vous vérifiez la cohérence entre :

  • ce que la caisse annonce

  • ce que vous avez réellement encaissé

Par exemple : si le rapport indique 100 € en CB, votre terminal bancaire doit afficher le même montant.

La TVA collectée¶

Le rapport détaille la TVA par taux en pourcentage avec :

  • le montant HT

  • la TVA

  • le montant TTC

Cette section est essentielle pour la comptabilité et les déclarations fiscales. Elle permet aussi de vérifier que chaque catégorie d’articles utilise le bon taux de TVA.

Les recharges cashless¶

Les recharges ne sont pas des ventes. Elles correspondent à de l’argent placé sur une carte, mais pas encore dépensé.

Le rapport distingue :

  • les recharges par CB

  • les recharges en espèces

  • les remboursements

  • les retours de consigne

Cette partie sert surtout à suivre les flux d’argent, pas le chiffre d’affaires.

Le solde de caisse¶

Le solde de caisse indique combien d’argent liquide doit se trouver dans votre tiroir.

Il prend en compte :

  • le fond de caisse de départ

  • les encaissements en espèces

  • les remboursements

  • les retours de consigne

Vous pouvez comparer ce chiffre avec l’argent réel pour détecter une erreur ou un oubli.

ici "vente directe" correspond à des consignes en espèces.

La monnaie dormante¶

La monnaie dormante (uniquement sur rapport classique) correspond à l’argent qui reste sur les cartes des clients.

Le rapport affiche :

  • ce qui a été rechargé

  • ce qui a été dépensé

  • ce qu’il reste sur l’ensemble des cartes

Le détail des ventes par article¶

Dans la partie basse du rapport, vous retrouvez chaque article vendu avec :

  • les quantités

  • le prix de vente

  • le prix d’achat

  • la TVA

  • le bénéfice

C’est ici que vous voyez :

  • ce qui se vend le plus

  • ce qui rapporte le plus

  • ce qui coûte cher

Le Rapport V2 propose une version plus visuelle avec des tris par point de vente ou responsable.

Les indicateurs de fin de rapport¶

En fin de document sur le Rapport classique, vous pouvez trouver :

  • le nombre de cartes utilisées

  • le panier moyen

  • la recharge médiane

  • le reste moyen sur carte

Ces indicateurs servent à analyser le comportement des clients et améliorer l’organisation.

Différence entre les types de rapports¶

Le contenu est globalement le même, seul l’affichage change :

  • Rapport classique : très détaillé, idéal pour la comptabilité

  • Ticket Z : version simplifiée pour la caisse

  • Rapport V2 : plus visuel, avec filtres et tris

Ce qu’on peut (et ne peut pas) faire avec un rapport¶

Un rapport permet d’analyser, pas de modifier :

  • on ne peut pas supprimer une vente

  • on ne peut pas effacer un paiement

  • on peut seulement relancer un rapport après une correction de configuration

C’est une garantie de fiabilité comptable.

Vous pouvez en revanche l’imprimer, l’envoyer par mail ou l’archiver.
