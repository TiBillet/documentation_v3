Problèmes de connexion Wi-Fi sur Sunmi V2S¶

(Cas d’usage : DHCP vs IP manuelle)

Un problème qui peut arriver même quand “tout fonctionnait avant”¶

Lors d’un festival, nous avons prêté plusieurs Sunmi V2S à un organisateur qui utilisait déjà Laboutik sans difficulté sur des événements précédents.

Cette fois-ci, impossible de connecter les nouveaux terminaux au réseau Wi-Fi du site.\ Pourtant :

  • Le réseau fonctionnait

  • Les autres appareils se connectaient

  • Les identifiants étaient corrects

  • Le matériel était opérationnel

Après plusieurs tests, nous avons identifié la cause.

La cause : une configuration réseau héritée¶

Les Sunmi V2S prêtés avaient été utilisés quelques mois auparavant sur un autre festival.\ Ce précédent événement utilisait une configuration réseau spécifique avec DHCP désactivé et des adresses IP manuelles.

Or, le nouveau festival utilisait un réseau public de mairie, configuré pour fonctionner uniquement en DHCP automatique.

Résultat :\ Les terminaux essayaient d’utiliser une configuration incompatible avec le nouveau réseau.

La solution : repasser en configuration automatique¶

Il a fallu modifier les paramètres Wi-Fi des Sunmi V2S pour :

  • activer le DHCP

  • supprimer les paramètres IP manuels

  • laisser le réseau attribuer automatiquement l’adresse

Une fois ce réglage fait, la connexion a fonctionné immédiatement.

Ce qu’il faut retenir¶

Quand du matériel est :

  • prêté

  • loué

  • réutilisé d’un événement à l’autre

Il peut conserver des réglages réseau invisibles mais bloquants.

Deux réseaux Wi-Fi peuvent fonctionner de manière très différente :

  • Certains exigent une configuration manuelle

  • D’autres imposent une configuration automatique

  • Les réseaux publics sont souvent plus stricts

Bonnes pratiques recommandées¶

Avant chaque événement :

  1. Vérifier les paramètres réseau des terminaux

  2. Tester la connexion sur site

  3. Réinitialiser les réglages si nécessaire

  4. Ne pas supposer que “ça marchera comme la dernière fois”

Si possible, se faire accompagner par un technicien réseau, un prestataire informatique ou une personne à l’aise avec les paramètres Wi-Fi avancés.

Cela évite de perdre un temps précieux le jour J.

Pourquoi c’est important pour Laboutik¶

Laboutik dépend d’une connexion stable.\ Un simple détail réseau peut empêcher :

  • l’encaissement

  • les recharges

  • l’accès à l’admin

  • la synchronisation des ventes
