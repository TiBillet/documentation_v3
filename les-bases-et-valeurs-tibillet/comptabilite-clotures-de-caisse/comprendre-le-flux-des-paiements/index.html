Comprendre le flux des paiements¶

Dans TiBillet / LaBoutik, il existe plusieurs types de paiements, plusieurs circuits d’argent et plusieurs comptes impliqués. Comprendre ce flux est essentiel pour savoir où va l’argent, à qui il appartient et comment il peut être remboursé.

Les choix faits à la création du lieu¶

Lors de la création de votre instance LaBoutik, deux décisions structurent tout le système de paiement :

  1. Le nom de votre monnaie Exemple : Salto, Peaksou, Ronds, Brebs, Houblons...

  2. Le type d’instance

  3. Instance autonome (non mutualisée - prestation commerciale)

  4. Instance fédérée (ouverte aux autres lieux du réseau)

Dans tous les cas, les recharges faites sur place (CB ou espèces) arrivent directement dans la trésorerie du lieu, car vous utilisez votre propre TPE ou votre propre caisse.

La différence principale concerne les recharges en ligne via le QR code.

Où va l’argent des recharges en ligne ?¶

Instance autonome¶

Les recharges faites via le QR code arrivent directement sur le compte Stripe du lieu. Ce compte Stripe est créé lors de la mise en place de votre instance.

L’argent reste techniquement sur votre compte, mais il appartient toujours aux utilisateurs.

Instance fédérée (mutualisée)¶

Les recharges en ligne arrivent sur le compte Stripe Connect (parent) de la coopérative TiBillet.

Chaque mois, les montants sont reversés au lieu concerné via un compte Stripe Connect (sous-compte).

Ces versements sont pour l’instant manuels, mais bientôt automatisés. Vous pouvez demander un versement à une date précise si nécessaire.

Dans votre espace Stripe, vous pouvez voir ce sous-compte en cliquant sur le logo de votre lieu en haut à gauche.

Ce système permet :

  • l’échange de monnaie entre lieux

  • les compensations entre structures

  • l’utilisation d’une même carte dans plusieurs endroits

Recharge ≠ Trésorerie¶

C’est un point très important :

Il appartient aux utilisateurs et peut être remboursé à tout moment. Le lieu a simplement l’obligation de le conserver et de le restituer si nécessaire.

Cela vaut pour :

  • les recharges en ligne

  • les recharges sur place

Les différents moyens de paiement dans les rapports¶

Dans les rapports TiBillet, on retrouve plusieurs catégories de paiement.

Voici leur signification réelle :

Local (ou nom de votre monnaie)¶

Correspond à l’argent rechargé sur place :

  • en espèces ou par carte bancaire

C’est l’argent directement encaissé par le lieu.

Espèces¶

Paiement en liquide pour :

  • une vente, une recharge, un retour consigne, un remboursement

Fédéré / Primary Asset¶

Argent rechargé en ligne via le QR code, puis dépensé dans le lieu.

Dans une instance fédérée, cet argent transite par la coopérative avant d’être reversé.

En ligne¶

Paiements Stripe directs via la billetterie ou les adhésions :

  • achat de billets, adhésions, réservations

Chèque¶

Paiement manuel (si activé).

Externe¶

Pas encore actif. Prévu pour d'autres types de monnaies.

Le cycle complet de l’argent¶

Voici le parcours typique :

Un utilisateur recharge :

  • soit sur place → argent dans la caisse du lieu

  • soit en ligne → argent sur Stripe (lieu ou coopérative)

Il dépense ensuite cet argent dans le lieu.

Le lieu peut :

  • encaisser les ventes

  • faire des remboursements

  • gérer les consignes

Mais ne peut pas considérer cet argent comme du chiffre d’affaires tant qu’il n’est pas dépensé.

Remboursements : règles importantes¶

Il existe deux circuits de remboursement distincts :

Recharge faite en ligne¶

➡ remboursement en ligne uniquement (via le QR code de la carte qui permet un remboursement Stripe)

Recharge faite sur place¶

➡ remboursement sur place uniquement (espèces ou cashless)

Les deux ne sont pas interchangeables.

Une recharge en ligne ne peut pas être remboursée en liquide. Une recharge sur place ne peut pas être remboursée en ligne.

C’est une règle comptable et technique.

Pourquoi TiBillet utilise Stripe¶

TiBillet n’est pas une banque, et n’a pas vocation à le devenir. Pour gérer les paiements en ligne de façon légale, sécurisée et conforme aux réglementations européennes, nous utilisons un prestataire spécialisé : Stripe.

Stripe est une infrastructure de paiement utilisée par des milliers d’organisations dans le monde. Elle permet de :

  • sécuriser les paiements par carte bancaire

  • respecter les obligations légales (lutte contre la fraude, conformité bancaire, KYC)

  • séparer clairement les fonds des utilisateurs et ceux des structures

  • automatiser les versements entre comptes

C’est aussi grâce à l’API Stripe que nous pouvons mettre en place la fédération des lieux et les versements automatiques de monnaie entre structures.

Sécurité et réglementation¶

Utiliser Stripe permet à TiBillet :

  • de ne pas être considéré comme un établissement bancaire

  • de ne pas stocker de données bancaires sensibles

  • de rester conforme aux réglementations européennes

  • d’assurer la protection des fonds utilisateurs

Les paiements passent directement par Stripe, pas par nos serveurs.

Les frais Stripe¶

Stripe applique des frais sur certaines transactions.

Cartes bancaires (Europe)¶

1,5 % + 0,25 € par transaction. Ces frais concernent :

  • la billetterie uniquement (adhésions, ventes directes en ligne)

Ils sont intégrés au fonctionnement normal du système.

Recharges cashless via QR code¶

Pour LaBoutik, les recharges en ligne via le QR code ont des frais d’environ 2,5 %.

Ces frais sont pris en charge par la coopérative TiBillet. Le lieu touche 100 % de l’argent dépensé par les utilisateurs.

Les utilisateurs ne voient pas de surcoût, et le lieu ne perd pas de revenu.

Et demain ?¶

Nous sommes actuellement en discussion avec d’autres prestataires de paiement afin d’obtenir des frais plus bas.
